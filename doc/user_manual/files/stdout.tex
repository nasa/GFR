\subsection{Display Output}
\label{SEC:Files:Display_Output}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

During a run job, if the current aggregate iteration is a multiple of
\inp[nmlOutput::DisplayInterval]{Display\_Interval},
convergence information for that particular iteration is written to
the display screen.
%
This information provides a high-level overview of the solution convergence.
%
Operating system commands can be used to capture or redirect the
display screen output to a file for later use.
